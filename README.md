# 나만의 퀴즈 게임

## 프로젝트 개요

터미널에서 동작하는 Python 퀴즈 게임입니다. 메뉴에서 번호를 골라 퀴즈를 풀고, 새 퀴즈를 추가하고, 퀴즈 목록과 최고 점수를 확인할 수 있습니다. 퀴즈와 최고 점수는 파일에 저장되어 프로그램을 종료했다가 다시 실행해도 유지됩니다.

## 퀴즈 주제와 선정 이유

- 주제: 축산(소, 돼지) 상식
- 선정 이유: 현업과 관련 된 상식 퀴즈를 만들어보고 싶었습니다.

## 실행 방법

Python 3.10 이상이 필요하며, 외부 라이브러리는 사용하지 않습니다.

```
python main.py
```

Windows에서 `python` 명령이 안 되면 `py main.py`로 실행합니다.

## 기능 목록

- 퀴즈 풀기: 저장된 퀴즈를 차례로 출제하고 정답 여부와 결과 점수를 보여 줍니다.
- 퀴즈 추가: 문제, 선택지 4개, 정답 번호를 입력해 새 퀴즈를 등록합니다.
- 퀴즈 목록: 등록된 퀴즈의 문제를 번호와 함께 보여 줍니다.
- 점수 확인: 지금까지의 최고 점수를 보여 줍니다. 퀴즈를 풀 때마다 비교해서 갱신합니다.
- 종료: 저장 후 프로그램을 종료합니다.
- 입력 처리: 공백 제거, 숫자가 아닌 입력, 범위 밖 숫자, 빈 입력을 안내 메시지로 처리합니다.
- 안전 종료: Ctrl+C 또는 입력 스트림 종료가 발생해도 저장 후 종료합니다.

## 파일 구조

```
quiz-game/

├── README.md      # 프로젝트 설명
└── .gitignore     # Git이 기록하지 않을 파일 목록
```

## 데이터 파일 설명 (state.json)

- 경로: 프로젝트 루트의 `state.json` (UTF-8 인코딩)
- 역할: 퀴즈 목록과 최고 점수를 저장합니다. 파일이 없으면 기본 퀴즈로 시작하고, 파일이 손상되면 안내 후 기본 퀴즈로 초기화합니다.
- 구조:

```json
{
    "quizzes": [
        {
            "question": "문제 내용",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 1
        }
    ],
    "best_score": 80
}
```

| 필드 | 설명 |
| --- | --- |
| `quizzes` | 퀴즈 목록 |
| `question` | 문제 |
| `choices` | 선택지 4개 |
| `answer` | 정답 번호 (1~4) |
| `best_score` | 최고 점수. 아직 퀴즈를 풀지 않았다면 `null` |
clone 실습: 복제한 저장소에서 추가한 문장입니다.
